Logic circuit simulator

First place, Audience Choice, UNF SoC Symposium | Spring 2026

A custom hardware description language with Python-style syntax and a restricted set of Verilog features, including its grammar. My interpreter compiles a circuit into a graph of components and computes its output. A Flask app shows the signal flowing through each logic gate.

IC floorplanner

Spring 2026

Implements algorithms from academic papers to compute chip layout area, using Intel's FloorSet data. Simulated annealing minimizes a cost function of area plus wire length, and an interactive PyQt app lets you watch the layout improve at each step.
